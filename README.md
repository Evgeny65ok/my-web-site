## ✨ Ключевые возможности

*   📱 **Mobile First**: Полная адаптивность под любые устройства (от смартфонов до десктопов).
*   🌓 **Смена тем оформления**: Темная и светлая темы с запоминанием выбора пользователя через `localStorage`.
*   📊 **Интерактивная статистика**: Плавная анимация цифр при загрузке главной страницы.
*   📝 **Умная форма контактов**: Автоматическое сохранение введенных данных в `localStorage` против случайной потери.
*   🎯 **Удобная навигация**: Автоматическая подсветка активного пункта меню при скролле или переключении страниц.
